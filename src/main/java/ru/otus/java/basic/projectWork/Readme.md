# Проект «Сетевой чат»
Сложность: 4

Примечание: проект является продолжением чата, реализованного на курсе

Цель работы: применить полученные на курсе знания

Задание: реализовать клиент-серверное приложение «Сетевой чат» на java.io, которое имеет следующие возможности:

### Серверная часть:

1. Запуск ServerSocket, прослушивание определенного порта и ожидание подключений
2. Обработка каждого подключения в отдельном потоке
3. Получение от клиентов сообщений: служебных команд и сообщений чата
4. Возможность регистрации и авторизации клиентов, с хранением данных о клиентах в базе данных
5. Рассылка сообщений всем авторизованным клиентам
6. Сервер к сообщениям должен добавлять время рассылки
7. Поддержка личных сообщений
8. Возможность изменения ника клиента по его запросу
9. Рассылка списка активных клиентов
10. Автоматическое отключение клиентов, которые не активны более 20 минут
11. Поддержка ролей пользователей (admin, user)
12. Возможность банить клиентов, баны могут быть по времени или перманентные (так может делать админ)
13. Возможность остановить сервер командой /shutdown
14. Возможность назначить пользователю роль администратора
15. *Добавить систему отдельных комнат. Есть общая комната куда все клиенты попадают по-умолчанию. 
Любой клиент может создать собственную комнату, и повесить на нее пароль. Можно запрашивать список комнат.
Можно заходить в созданные комнаты, командой /enter [room_name] [room_pass, если он есть].
В одно время пользователь может находиться только в одной комнате. 
При подключении можно ему отправлять историю сообщений из этой комнаты. 
Если в комнату давно никто не заходил (7+ дней), то она удаляется. 
У каждой комнаты есть владелец, один юзер не может владеть более чем 5 комнатами.
Владелец комнаты при помощи команды /kick может отключить любого клиента из комнаты, а администратор из Общей комнаты.

###     Клиентская часть:

1. Возможность подключиться к серверу
2. Возможность отправлять и получать сообщения
3. Возможность отключаться от сервера с помощью команды /exit
   
####  Все служебные действия могут выполняться через обычные сообщения, начинающиеся с /

    /reg – регистрация
    /auth – аутентификация
    /help - показать доступные команды
    /w – личное сообщение
    /users – список активных клиентов
    /rename – смена ника
    /exit – выход (для клиента)
    /logout - выйти из системы
    /kick - исключить указанного пользователя из чата|комнаты
   
    /ban – бан пользователя Перманентный и временный(для админа)
    /unban - удалить пользователя из Бана (для админа)
    /add_admin - назначить пользователю роль администратора (для админа)
    /remove_admin - удалить права администратора (для админа)
    /shutdown – остановка сервера (для админа)

    /listrooms - показать список доступных комнат
    /createroom - создать новую комнату
    /enter <room_name> - войти в комнату  
    /deleteroom - удалить комнату
    /leaveroom - покинуть текущую комнату
    /invite - пригласить пользователя в комнату
    /myinvites - посмотреть свои приглашения
    /decline - отклонить приглашение в комнату
